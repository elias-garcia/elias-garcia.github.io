For a few years my site was a hosted profile: one column, small type, dates in the margin, nothing to configure. When the service shut down, I exported my profile and never quite replaced it.

This site is the replacement. I wanted to keep what that profile got right, and add the two things it never gave me: room to write up projects properly, and a blog.

## What I kept

One column, about 640 pixels wide. Dates live in a left gutter, so a whole career scans in a second. One typeface. Grey for context, black for the thing itself. No cards, unless the content is something you can open.

## Spending the motion budget

I wanted the site to feel crafted without feeling busy, so motion follows a few rules.[^1] Pages arrive in one quick motion. Everything else responds to something you did, and interface feedback stays under 300 milliseconds.

Easing does most of the work. Things entering the screen use ease-out: they arrive fast and settle, which reads as responsive. Linear is for things that never stop, like a spinner. Press replay and compare.

<EasingDemo caption="Same distance, same 600 ms. Only the curve changes." />

I tried staggering every element in, and it felt slow and uneven, so the page now arrives as one piece: the content rises six pixels and fades in over a quarter of a second, while the header stays exactly where it is.[^2] Moving between pages, the old content fades out first, so it reads as one continuous site. This is the whole thing:

```css
/* the page arrives as one piece */
@keyframes page-in {
  from { opacity: 0; transform: translateY(6px); }
}
@keyframes page-fade {
  from { opacity: 0; }
}
main {
  animation: page-in 250ms cubic-bezier(.22, 1, .36, 1) backwards;
}
@view-transition { navigation: auto; }
/* reduced motion: still a fade, just no movement */
@media (prefers-reduced-motion: reduce) {
  main { animation: page-fade 150ms ease-out backwards; }
}
```

## Details you only notice when they're missing

Hover any list and the other rows step back. Search is one keystroke away on every page. The header knows how far you've read. None of it is necessary, and all of it is the kind of detail I care about in product work.
