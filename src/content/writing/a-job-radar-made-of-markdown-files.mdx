## A folder instead of an app

There is no repository and no backend. Roleburn is a folder of markdown files that scheduled tasks in Claude Cowork read:

- `cv.md`, the source of truth.
- `criteria.md`, what a good match means: remote from Europe, senior, Web3, payments, AI.
- `companies.md`, the teams worth watching.
- A few prompts that tell the agent how to search, score and summarise.

On a schedule, a task reads the folder and writes the digest.
