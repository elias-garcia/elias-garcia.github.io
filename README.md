# eliasgarcia.dev

Personal site of Elías García, built with Astro from a Claude Design handoff.

- `CLAUDE.md`: ground rules for Claude Code.
- `PLAN.md`: build order and open items for the redesign (temporary).
- `design/`: specification (`DESIGN.md`), reference HTML, screenshots and original assets. Reference only; the site never imports from it.
- `src/content/`: site content as YAML data and MDX (example content for the first version).
- `src/styles/tokens.css`: design tokens.
- `public/`: favicon, app icons and the CV PDF.

Open `design/reference/home.html` in a browser to see the static reference of a page (the images load from `design/assets/`).
