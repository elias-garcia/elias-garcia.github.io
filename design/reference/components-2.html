Lists and cards

List row

Date gutter of 112px, title, one muted line. No dividers; other rows step back on hover. A row is a link only if it has somewhere to go; otherwise it is a plain row with no hover. A row can carry one attachment (see List row attachment).

List row attachment

Optional media under a list row’s text, starting exactly under the title (it wraps like the row: an empty 112px date column beside it, which drops away on phones together with the date). A row has at most one attachment, of one kind:

Photos: 1 to 3 images as 3:2 thumbnails, each a third of the text column, in a row of three (8px apart, 8px radius, hairline border); fewer stay left-aligned at the same size; never more than three. Every image has descriptive alt text. Each photo is a button (“Open photo 2 of 3: {talk}”) that opens the image viewer. On narrow rows (phones, where the date sits above the title) the photos show full width in the page instead: one fills the text column; several scroll sideways inside it with the next one peeking 32px, never past the page margins. It switches at the row’s own width (436px, the point where the date moves up), not a screen breakpoint, so a tablet with the date column keeps the thumbnails. Video preview: exactly one bordered card spanning the full text column (the same width as a row of photos), with a thumbnail the same size and shape as a photo (a third of the column, 3:2) and a 32px play button centred on it, a label and its source with ↗, e.g. “Watch the trailer / YouTube ↗”. It is its own link, separate from the row’s link; it opens the video elsewhere and never embeds a player.

Image viewer

Opens when a photo attachment is clicked. A modal dialog in the search palette’s language: a card up to 840px wide (70% of the window, never taller than it) with the photo on top, cropped to fill a 3:2 frame so the card is the same size for every photo, the talk title, place and date below with the position (“1 / 3”), and a footer of key hints; ‹ › on the photo’s sides, × in its corner, all 40px round buttons. The page behind dims with the scrim and doesn’t scroll. Focus moves to the viewer itself on open (no ring on it; Tab reaches × and ‹ ›), stays inside while open and returns to the thumbnail on close. Esc, ×, the backdrop and a swipe down close it; ← → and swipes move. One photo: no arrows and no count. Phones (under 640px): the platform photo viewer, always on black: photo edge to edge, caption below it, then ‹ › with dots at the bottom within thumb reach; × top right; 44px buttons. Dragging down moves the photo and closes it past 80px, otherwise it springs back. Reduced motion: a fade only.

Used on: Home (talk photos). To see it open over the page, set Tweaks › Image viewer › open on any Home artboard.

Prose

Heading, paragraph, link, footnote

Every other Markdown element (lists, quotes, tables, inline code, checklists, callouts) is on the Prose reference artboard.

Section headings get a # anchor on hover. Links inside prose are indigo with a soft underline and never carry the ↗ arrow; the arrow is only for standalone links (contact rows, the course row, project facts). Footnote markers are links to a Notes section at the end of the article, below a short 64px rule (numbered, 14px grey). Each note ends with a ↩ link (24px target) back to its marker, which lands a third of the way down the screen. Arriving at a note or back at a marker briefly lights it up. No popovers. Rhythm: 24px between paragraphs; 48px above an h2 and 16px below it, 32px above an h3 and 12px below, 24px above an h4 and 8px below; 32px around figures, code blocks and tables; 8px between list items.

Used on: posts, case studies

MDX: h2 · p · a · footnotes
