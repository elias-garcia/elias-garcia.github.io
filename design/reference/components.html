Prose

Heading, paragraph, link, footnote

Every other Markdown element (lists, quotes, tables, inline code, checklists, callouts) is on the Prose reference artboard.

Section headings get a # anchor on hover. Links inside prose are indigo with a soft underline and never carry the ↗ arrow; the arrow is only for standalone links (contact rows, the course row, project facts). Footnote markers are links to a Notes section at the end of the article, below a short 64px rule (numbered, 14px grey). Each note ends with a ↩ link (24px target) back to its marker, which lands a third of the way down the screen. Arriving at a note or back at a marker briefly lights it up. No popovers.

Used on: posts, case studies

MDX: h2 · p · a · footnotes
