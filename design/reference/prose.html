Prose reference

Style reference ·Every element a post can contain

This page uses every element a Markdown or MDX post can produce, styled exactly as posts are. Paragraphs are 16px with a 1.6 line height. Text can be bold, italic or struck through, and links can stay inside the site or go to another site; links in a sentence never get the external arrow.1 Inline code looks like prefers-color-scheme, and takes the colour of a link around it, as in the astro:content guide. Keys look like ⌘ K.

#Headings

The post title is the only level-one heading. Sections start at level two, like the one above.

A level-three heading with code

Use it to break a long section into parts. It is 20px, one step above the text, and set apart by weight.

A level-four heading

The smallest heading, at 16px: the size of the text, set apart by weight. If a post needs more levels than this, it probably needs to be two posts.

#Lists

  • An unordered list uses small grey dots.
  • Items can run onto two lines, and the second line stays aligned with the first, without hanging under the dot.
  • Nested items get a hollow dot:
    • one level in,
    • and no deeper.
  1. An ordered list keeps its numbers grey.
  2. Numbers line up, even past nine.
  3. Use it when the order matters, like steps.

  • A task still open

#Quotes and breaks

A quote is set off by a grey rule, not by colour or italics, so long quotes stay comfortable to read.

#Code

Code blocks show their language and a Copy button. The syntax theme is mostly neutral: keywords in indigo, values in a deeper indigo, names in the text colour, and comments and punctuation in grey. Highlighted lines get a light indigo background and a rule on the left.2
